# VenturePilot Deals — Free Website Prototype

This is a standalone, mobile-friendly static website for **VenturePilot Deals**, the physical-product affiliate project under the ReadyMade Digital umbrella.

## Run locally

Open `index.html` in Chrome, Edge, or another browser. No account, server, Python, or payment is required.

For a local development server (optional): `python -m http.server 8000` from this folder, then visit `http://localhost:8000`.

## What works

- Responsive landing page
- Six category cards with working search and category filters
- Three general buying-guide previews in accessible dialogs
- Product-comparison checklist
- Affiliate disclosure and methodology sections

## What is deliberately NOT active

- No retailer affiliate links, commissions, or fabricated product prices
- No merchant data feeds, API keys, analytics, cookies, or tracking scripts
- No auto-publishing, order processing, or external calls
- No connection to Payhip, Pinterest, or existing ReadyMade Digital accounts
- No actual hands-on reviews or unverified product rankings

## Before public launch

1. Check name/domain availability and affiliate program terms.
2. Apply to retailers as required, with owner approval for agreements.
3. Verify current products, prices, specifications, commission terms, and permitted image use.
4. Add merchant-compliant links and clear affiliate disclosures near recommendations.
5. Prepare a privacy policy, contact details, and legal disclosures for actual data practices.
6. Deploy to a static host under a separate account and connect analytics only with appropriate privacy controls.
7. Add a separate agent service with narrowly scoped publishing credentials and a human approval queue. Do not give it credentials for Payhip or the existing Pinterest account.

## Owner approval policy

Human approval required before spending, contracts, supplier orders, payment execution, customer fulfillment, or business registration. No financial execution functionality exists in this website.

## Budget

This prototype costs $0 to run locally. Hosting and domain registration are optional future choices subject to approval. $500 remains the maximum planned startup budget, not an amount committed.
